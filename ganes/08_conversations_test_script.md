# Conversations: chat uji di website

Buka website di HP, ketik satu per satu lewat widget. Hasilnya muncul di **Conversations**, dan yang meminta orang masuk ke **Needs Attention**.

1. "Halo, rice cooker mini ada?" → stok habis (kait S03)
2. "Popok celana ukuran L ada?" → L habis, tawarkan M
3. "Ada promo apa?" → tiga promo
4. "Cicilan 0% pakai kartu apa?" → kemungkinan gagal menjawab → masuk Answer Gaps (kait S09)
5. "Berapa lama batas retur?" → jawaban bisa 7 atau 30 hari (kait S15)
6. "Pesanan TAA-240101 sampai mana?" → butuh add-on Order Tracking
7. "Minggu buka jam berapa?" → 09.00–20.00 (kait S14)
8. "Earphone bluetooth spesifikasinya apa?" → deskripsi kosong (kait S11)
9. "Bisa kirim ke luar negeri?" → tidak ada jawaban → Answer Gaps
10. "Halo, saya Rina. Bisa retur? Saya mau bicara dengan orang." → **wants a person** → Needs Attention (kait S01)
